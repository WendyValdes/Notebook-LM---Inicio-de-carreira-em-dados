📊 Data Career Blueprint
Construindo conhecimento sobre a carreira em dados com IA e NotebookLM

📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio da DIO (Digital Innovation One) com o objetivo de explorar o uso de Inteligência Artificial como ferramenta de aprendizagem ativa.

Utilizando o NotebookLM, foi criado um Caderno Temático sobre o início da carreira em dados, reunindo conteúdos estruturados sobre as principais habilidades exigidas no mercado.

O resultado final foi a criação do e-book "Data Career Blueprint", um guia introdutório sobre:

Python para análise de dados

SQL para consulta de dados

Power BI para visualização e dashboards

🎯 Objetivos do Projeto

Organizar conhecimento utilizando IA

Aplicar engenharia de prompts

Criar um miniguia estruturado de estudos

Consolidar conhecimentos sobre carreira em dados

Construir um projeto relevante para portfólio

🧠 Stack de Tecnologias
Ferramenta	Uso no projeto
Python	Processamento e análise de dados
SQL	Consulta e manipulação de dados
Power BI	Visualização de dados
NotebookLM	Organização do conhecimento com IA
⚙️ Arquitetura da Stack de Dados

Esse fluxo representa um pipeline típico de análise de dados utilizado por analistas.

📚 Curadoria de Fontes

Para alimentar o NotebookLM foram utilizadas fontes abertas sobre:

Introdução à análise de dados

Python para Data Analysis

SQL para consulta de dados

Visualização com Power BI

Essas fontes serviram como base para gerar resumos e insights utilizando IA.

🤖 Engenharia de Prompts

Durante o desenvolvimento do projeto foram utilizados diferentes prompts para extrair conhecimento das fontes.

Exemplos de Prompts

Prompt 1

Explique quais são as habilidades essenciais para iniciar na carreira de analista de dados.

Prompt 2

Explique como Python é utilizado na análise de dados com exemplos práticos.

Prompt 3

Mostre exemplos de consultas SQL utilizadas no dia a dia de analistas de dados.

Prompt 4

Explique como dashboards ajudam empresas a tomar decisões baseadas em dados.

⚠️ Aprendizados (Cicatrizes)

Durante o uso do NotebookLM foram identificados alguns desafios:

Algumas respostas da IA eram muito genéricas

Foi necessário refinar os prompts

Testar diferentes perguntas melhorou os resultados

Esse processo demonstrou a importância da engenharia de prompts para extrair conhecimento mais útil da IA.

📖 Resultado Final

O resultado final foi a criação do e-book "Data Career Blueprint", contendo:

Introdução à carreira em dados

Explicação das principais ferramentas

Estrutura de aprendizado para iniciantes

Resumos organizados sobre Python, SQL e Power BI

Esse material funciona como guia inicial para quem deseja entrar na área de dados.
